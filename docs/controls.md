# ZS800I 237371 控制实现与验证范围

## 来源与型号约束

- [237371型号表](https://github.com/sxz799/jomoo-sq9650-homeassistant/blob/797a13e206871d8e5e4fa717429606be8d4e7a3c/OUTPUT/config/device_enum.js#L10617-L10732)：`bleProtocol=0`，使用F3F4；水温/座温上限5、风温上限3。盖圈来源EA，非E2/E9。
- [同协议控制器](https://github.com/sxz799/jomoo-sq9650-homeassistant/blob/797a13e206871d8e5e4fa717429606be8d4e7a3c/OUTPUT/utils/bluetooth/toilet/ToiletController.js#L651-L686)：动作和设置的19字节模板。
- [wilton999/JomooToilet](https://github.com/wilton999/JomooToilet)：同族Python控制实现，原作者仅说明ZS781J/279331实测，不等于237371已经全部验证。
- sxz799仓库现成HA组件是SQ9650的另一套FC协议；本项目参考其公开通用控制器，而非搬用SQ9650的独立盖圈控制字节。

## 实际验证与剩余事项

2026-10-31，通过254上的HA原生`number.set_value`、`switch.toggle`及`switch.turn_on`服务，协调器经过真实蓝牙下发并读取设备通知：

| 项目 | 实机回读 | 范围 |
|---|---|---|
| 风温 | 2 → 1 → 2、1 → 0 → 1，最终独立恢复2，成功步骤均confirmed | 已验证19字节设置路径与档位0/1/2，不是物理温度测量 |
| 氛围灯 | 开 → 关 → 开，每步confirmed | 已验证短帧控制和FA状态位 |
| 水温/座温 | 源码映射＋离线构帧验证 | 尚未实际改变设置 |
| 其他6个开关 | 源码映射＋离线构帧验证 | 尚未逐项实物操作 |
| 冲水、盖圈、清洗、暖风等动作 | 源码动作码＋离线构帧/状态确认测试 | 尚未逐项启动实物动作；需要在现场核对效果 |

调试过程中一次重连失败导致当轮风温恢复未完成；最终于19:37通过独立HA服务将原风温2档回读确认为confirmed，氛围灯为开启，水温/座温为3/3。最终0.2.0安装包的四次可逆控制验收均确认，且部署代码逐文件与ZIP一致。随后删除全部临时测试/恢复自动化，重启核对38个实体的中文名称、状态和面板引用。没有把发送完成、注册实体或HTTP 200冒充为物理动作完成。

## 通信与状态判定

1. 刷新和控制共用锁。当前扫描器实际保有目标时直接使用该连接来源；只有历史记录而无当前来源时请求HA共享扫描。连接重试只用于建连，不重放动作。
2. 在`start_notify`之前启用本连接的接收器，接收订阅握手中的初始FA。仅处理校验有效且来源地址为21的FA/E9/EA。
3. 0.3.0只复用传输连接，不复用旧控制基准：19字节操作仍要求本事务新E9和足长FA，盖圈要求新EA；独立短开关不消费这些基准，因此省去预读。不从持久化旧快照补齐构帧字段。
4. 实机观察到重连首条E2有时仅回E9/EA；同连接有界重复E2后收到FA。因此预读最多3次；0.3.0各次通知等待最多1秒，取代0.2.0的8秒总等待。FFE1 Read诊断曾返回单字节00，不作为FA基准，正式路径仅使用实际通知。
5. 等待稳定后再次检查最新状态并构帧：档位需空闲；盖圈需无人、空闲且停止运动；清洗和烘干需着座。其他时刻在中文界面报告原因。
6. 每次控制只写一次。写前清空阶段观察及解析器残片；写后只用本次通知确认；0.3.0先留0.25秒处理时间，必要时以最多1秒间隔进行约9秒窗口的只读状态查询。盖圈确认还要求运动位归零。
7. 短开关/档位通过目标字段匹配确认；冲水/清洗/暖风通过相应运行状态位观察。瞬时状态可能错过，因此“已发送，未确认”不是“没有执行”，应先查看设备实际状态再决定操作。
8. 命令已写入后出现读回异常保留`sent_unconfirmed`，不自动补发。控件不乐观更新，保留最近真实回读与各字段观察时间。

## 19字节模板与限制

```text
F3 F4 0F 92 21 CMD B6 B7 B8 B9 B10 B11 B12 B13 B14 B15 B16 CHECK FC
CHECK = sum(frame[2:-2]) & 0xff
```

- B6：水温、自动翻盖、手势/夜灯所在低位；FA中动态疏通高位不回写。FA的bit0/bit2承接同构布局，独立语义尚未实物验证。
- B7/B8：根据动作选择臀洗或妇洗喷嘴/压力，保留已映射的座温、风温、节电/光感位。
- B9幅度来自FA[13]，不是直接复制FA[9]（后者为妇洗参数）。
- B10为上游普通模板的0；B11风速字段来自FA[10]，不是FA[11]的灯/UV位。
- B12–B16采用上游无定时、非自定义用户模板的0。

这不是未知位全部无损的读改写，也不支持把FA原始帧改个动作码直接发回。需要自定义用户/定时模式时应另行捕获同型号APP实际TX并验证，不能用本模板假装覆盖。
